# doktor-debug/.github

Version: 2.3.0
Date: 2026-07-19

This repository publishes the `doktor-debug` organization profile and its concise repository map. GitHub renders `profile/README.md` at <https://github.com/doktor-debug>.

The profile describes fourteen active `doktor-debug/*` repositories. Authenticated write gates are provided separately by the private external control plane [`n-e-o-w-u-l-f/myAPI`](https://github.com/n-e-o-w-u-l-f/myAPI); it is not a `doktor-debug` content repository.

Read `AGENTS.md` before changing profile content. `profile/TOC1.md`, `profile/TOC2.md`, and `profile/TOC3.md` are the maintained navigation pages; no additional profile index is required.

This public repository must not disclose secrets, private payloads, personal data, or non-public archive/storage locators.
